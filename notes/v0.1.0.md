## What's new

First release: the ARM64 ports for ArmadaOS in one list in the Quick Access menu.

- **Pinyon Shift** and **FIFA Street** install from Game Mode: pick your disc image with Decky's file picker and the build runs in the background, even with the menu closed or another game running. You get a notification when it ends and the game lands in your Steam library without restarting Steam.
- Installs you already made with a launcher are picked up as they are (**It is already installed**), or from the launcher folder you choose.
- A notification when a port has a new release (for FIFA Street, also new scripts on main), and an **Update** button that replaces the launcher and rebuilds from the game files already extracted.
- The other ports (Saints Reborn, Midtown Madness 3, Rusty MCLA, Road Trip Adventure, ReSkate, Azimuth Turnip) are listed with their newest release and notes; they still install with their own launcher or README.

## Putting it on the handheld

Decky Loader is needed; ArmadaOS has it already. In Desktop Mode save `ArmadaPorts-v0.1.0.zip` and `install.sh` side by side, run `bash install.sh` in a terminal there and type your password when asked (Decky's plugin folder belongs to root). Decky restarts on its own; in Game Mode the plugin is under the plug icon of the Quick Access menu. From the next version on, the plugin updates itself from its own panel.
