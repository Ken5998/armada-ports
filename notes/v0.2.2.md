## What's new

- **Check for updates** no longer runs into GitHub's limit of 60 requests an hour. The plugin keeps GitHub's last answer for each port and only asks whether it changed, which GitHub does not count; once the limit is reached anyway, the panel goes on with the last known releases instead of an error.

## Putting it on the handheld

From 0.2.x: open Armada Ports, press **Check for updates**, then **Update Armada Ports to 0.2.2** at the bottom of the panel. If 0.2.1 still shows the rate-limit error, wait for it to clear (at most an hour) or install from Desktop Mode: `bash install.sh` next to `ArmadaPorts-v0.2.2.zip`.
