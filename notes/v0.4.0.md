## What's new

- **FH1 ReImagined and inFAMOUS Reborn are in the app.** Install, update and play both from Game Mode, no more trips to Desktop Mode to update them.
- **FH1 ReImagined** asks for Title Update 4 after the disc image (found for you like the disc, or build without it). Update keeps the disc and update the last build used, and follows the repository's main, so new patches (the native renderer, for instance) arrive without waiting for a launcher release. DLC and car packs still install from its launcher.
- **inFAMOUS Reborn** has no launcher: the app runs its build itself and offers **Update** whenever main has new patches, showing the commit it would update to. An install built by hand from a clone of the repository is found as it is, and that clone is kept so an update only recompiles what changed.

## Getting it on the RP6

Quick Access menu, Decky, Armada Ports, **Check for updates**, then **Update Armada Ports to 0.4.0**. Open the app again: the two new covers are after Skate 3 Recomp. If you already built them, they show up as installed.

First time: in Desktop Mode put `ArmadaPorts-v0.4.0.zip` and `install.sh` in one folder and run `bash install.sh` there.
